# 캐러셀 양식 (10장, 1080×1350)

완성 예시:
- `sample-2026-10-us-treasury.html`: 블랙록 주간 코멘터리 2026.9.28, 미국채 금리
- `sample-2026-10-equities-vs-rates.html`: 모건스탠리 팟캐스트 2026.10.2·9.28, 금리와 주식
- `sample-2026-10-diesel.html`: 모건스탠리 팟캐스트 2026.9.24, 디젤·유가

## 장 구성

| 장 | 역할 | 태그 |
|---|---|---|
| 1 | 표지 훅: 큰 숫자 하나 + 질문형 제목 | 없음 |
| 2 | 3줄 요약 | 하우스 태그 (예: BlackRock View) |
| 3 | 차트: 무슨 일이 있었나 | Data · FRED |
| 4 | 원인 ① | 하우스 태그 |
| 5 | 원인 ② (차트 가능) | 하우스 태그 |
| 6 | 하우스 시각: 원문 핵심 문장 번역 인용 | 하우스 태그 |
| 7 | 포지셔닝 표 | 하우스 태그 |
| 8 | 반대 시각·리스크 | Editor's Note |
| 9 | 한국 투자자 체크포인트 | Editor's Note |
| 10 | 용어 2개 + 태그 범례 + 출처 + 고지 | 없음 |

## 출처 태그 규칙

- **하우스 태그** (`BlackRock View`, `Morgan Stanley View`, `Fed` 등, `sources.yaml`의 `tag`): 리포트에 있는 내용만 써요.
  내 표현으로 바꿔 요약한 문장도 원문 주장과 같아야 해요.
- **Editor's Note**: 운영자 해석. 제목 아래에 "리포트가 아닌 운영자의 해석이에요"를 한 줄 적어요.
- **Data · FRED**: 공공 데이터로 직접 그린 차트. 원문에 없는 수치를 넣었으면 하단에 "원문에 없음"을 표시해요.
- 한 장 안에서 하우스 의견과 운영자 해석을 한 문장에 섞지 않아요.
- 8장(반대 시각)도 다른 하우스나 같은 회사 다른 전략가의 의견이면 그 하우스 태그를 붙여요. 운영자 의견일 때만 Editor's Note예요.

## 게시 전 체크

1. 6장 인용문과 7장 포지션을 `out/<날짜>/texts/`의 원문 텍스트와 대조
2. 표지 숫자는 게시 당일 최신 값으로 (`python -m macrobrief data fred DGS10 --start <최근>`)
3. 민간 자료(private)는 원본 차트를 캡처하지 않고 공공 데이터로 다시 그리기
4. 캡션에 출처, 원문 날짜, "투자 권유 아님" 고지
